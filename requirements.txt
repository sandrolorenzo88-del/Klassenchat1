# Klassenraumchat MVP

Minimaler Flask-basierter Klassenchat für Deployment auf Render.

## Features

- Klassenraum beitreten
- Klassenraum verlassen
- Teilnehmer anzeigen
- Nachrichten senden
- Gemeinsamer Chatverlauf
- Online-Status anzeigen

## Lokaler Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Deployment auf Render

1. Repository auf GitHub erstellen
2. ZIP entpacken und pushen
3. Neues Web Service in Render erstellen
4. Repository verbinden
5. Render erkennt automatisch die render.yaml

## Architektur

- Flask Web Application
- Gunicorn als WSGI-Server
- Render als Hosting-Plattform
- HTML/CSS Frontend ohne zusätzliche Frameworks
